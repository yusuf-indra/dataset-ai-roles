# Interactive Supplementary Materials

Static research data explorer. Open `index.html` locally or deploy via GitHub Pages (Settings → Pages → Deploy from a branch → main → /(root)).

This publication candidate includes bibliographic metadata, DOI links, screening status and categorical coding only. Raw abstracts, screening reasoning, verbatim evidence, internal PDF URLs and source IDs are not published.
